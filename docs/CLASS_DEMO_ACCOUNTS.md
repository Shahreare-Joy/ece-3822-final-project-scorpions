# Class Demo Accounts

These are classroom/demo passwords only. They are stored in
`data/demo_accounts.json` and are not secure production credentials.

Edit accounts with:

```powershell
python -B tools\manage_demo_accounts.py list
python -B tools\manage_demo_accounts.py set-password <username> <new_password>
python -B tools\manage_demo_accounts.py upsert <username> "<Display Name>" <password>
```
